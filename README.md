# CDN Mark Life

A CDN and file management platform built on AWS S3 + CloudFront with a Convex real-time backend.

## Architecture

```
Browser ──(HTTPS)──► CloudFront ──► S3    (cdn.mark-life.com — Vite React SPA)
Browser ──(WSS)────► Convex Cloud          (real-time DB, auth, file metadata)
Browser ──(HTTPS)──► CloudFront ──► S3    (static.mark-life.com — media files)
```

## What's Inside

- `apps/web` — Vite + React SPA (deployed to S3/CloudFront)
- `apps/convex` — Convex backend (schema, queries, mutations, actions)
- `packages/ui` — Shared shadcn/ui component library
- `packages/env` — Environment variable validation (Zod)
- `packages/typescript-config` — Shared TypeScript configs
- `infrastructure/terraform` — AWS infrastructure (S3, CloudFront, Route 53, ACM, IAM)

## Stack

- **Runtime**: Bun
- **Build**: Turborepo
- **Frontend**: Vite + React + React Router
- **Backend**: Convex (real-time database, auth, actions)
- **Auth**: WorkOS via Convex AuthKit
- **Storage**: AWS S3 (prefix-based account isolation)
- **CDN**: AWS CloudFront
- **DNS/SSL**: AWS Route 53 + ACM
- **Infrastructure**: Terraform
- **UI**: shadcn/ui + Tailwind CSS
- **Linting/Formatting**: Ultracite (Biome)
- **Pre-commit**: Husky + Ultracite
- **CI/CD**: GitHub Actions

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) >= 1.3.9
- [Terraform](https://www.terraform.io) >= 1.0
- AWS account with Route 53 hosted zone for `mark-life.com`
- [Convex](https://www.convex.dev) account

### Setup

```bash
bun install
```

### Development

```bash
# Start both the Vite dev server and Convex dev watcher
bun run dev
```

### Environment Variables

Copy `.env.example` to `.env.local` and fill in the values:

```bash
cp .env.example .env.local
```

Set Convex environment variables for the backend:

```bash
cd apps/convex
bunx convex env set AWS_REGION eu-north-1
bunx convex env set AWS_ACCESS_KEY_ID <your-key>
bunx convex env set AWS_SECRET_ACCESS_KEY <your-secret>
bunx convex env set S3_BUCKET_NAME <your-bucket>
```

### Infrastructure

```bash
cd infrastructure/terraform
terraform init
terraform plan
terraform apply
```

```bash
bunx shadcn@latest add button -c packages/ui
```

Then import:

```tsx
import { Button } from "@workspace/ui/components/button"
```

## File Management

Files are stored in S3 with prefix-based account isolation:

```
s3://bucket/
  {account-slug}/
    images/
      logo.png
    documents/
      report.pdf
```

Convex tracks file metadata (name, path, content type, size, uploader) and provides real-time subscriptions for file tree updates. Uploads use S3 presigned URLs generated by Convex actions — files go directly from the browser to S3.

## Deployment

Pushing to `main` triggers the GitHub Actions pipeline:

1. Builds the Vite app with `VITE_CONVEX_URL` baked in
2. Syncs build output to the app S3 bucket
3. Invalidates the CloudFront cache
4. Deploys Convex backend functions
